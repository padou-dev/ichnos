# Changelog

All notable changes to Ichnos are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-21

### Added

- Main window: file list with thumbnails, grouped tag table, preview and a
  summary of pending changes.
- Presets: Location only, Share-safe and Strip all, plus ticking individual tags.
- Editing of artist, copyright, date and description tags.
- Cleaned copies written next to the originals and verified after writing.
- Protection for orientation, colour profiles, image structure and RAW data.
- Command line: `ichnos show`, `ichnos strip`, `ichnos presets`.
- Omarchy theme support with live theme switching.
- Desktop file, AppStream metadata, icon, man page and an Arch PKGBUILD.
